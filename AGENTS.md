# Repository workflow

The user requires every update to this project to be committed and pushed to https://github.com/acGhostes/jelly-cli. After making changes, run relevant checks, commit, and push the working branch. Do not leave completed updates only in the workspace. If authentication or a remote rejection blocks the push, explain the blocker explicitly.

Preserve remote history and user changes; do not force-push without explicit authorization. Keep credentials, sessions and generated build files out of Git.

Installers and release assets are distributed through GitHub Releases. Keep downloads pinned to a version and checksum verified. Do not restore the personal domain as the default install source. Bump the version for changed release contents; do not replace published versioned assets.
